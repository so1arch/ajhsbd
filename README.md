# MicStudio

Программа для Windows: берёт ваш микрофон, делает звук «студийным» и отдаёт его
в виртуальный микрофон, который можно выбрать в Discord и любых других программах.
Живёт в трее, есть окно с ползунками, настройки сохраняются.

## Что делает с голосом
Фильтр низких (убирает гул) → шумовые ворота → шумоподавление → эквалайзер
(тепло, «бочка», чёткость, воздух) → компрессор → де-эссер → лимитер.

## Сборка на GitHub (без установки чего-либо на ПК)
1. На github.com: **New repository** → имя `MicStudio` → **Create repository**.
2. Распакуйте архив с исходниками. В репозитории нажмите **uploading an existing file**
   и перетащите в окно ВСЁ содержимое папки (файлы + папки `Dsp` и `.github`). **Commit changes**.
3. Откройте вкладку **Actions**. Сборка «Build MicStudio» стартует сама (2–4 минуты).
   Если не стартовала: Actions → Build MicStudio → **Run workflow**.
4. Когда появится зелёная галочка, откройте этот запуск → внизу **Artifacts** → `MicStudio-win-x64`.
   Скачается zip, внутри `MicStudio.exe`.
5. Положите `MicStudio.exe` в постоянную папку (например `C:\Programs\MicStudio`) и запустите.
   Если Windows пишет «Защитник SmartScreen» — **Подробнее → Выполнить в любом случае**
   (программа не подписана сертификатом).

## Первый запуск: виртуальный микрофон (один раз)
Windows не позволяет обычной программе создать новый микрофон — для этого нужен аудиодрайвер.
Программа сама определяет, установлен ли он, и показывает кнопку **Установить**:
1. Откроется официальная страница VB-CABLE (vb-cable.com) — скачайте драйвер.
2. Распакуйте, правой кнопкой на `VBCABLE_Setup_x64.exe` → «Запуск от имени администратора» → **Install Driver**.
3. Перезагрузите ПК. MicStudio подключится автоматически.

## Discord
Настройки → Голос и видео → **Устройство ввода: CABLE Output (VB-Audio Virtual Cable)**.
В Discord отключите шумоподавление и автоматическую регулировку усиления.
Устройство вывода по умолчанию в Windows менять не нужно.

## Если что-то не так
- Шипит между словами → сдвиньте «Шумовые ворота» вправо, ориентируйтесь на белую метку на шкале «Вход».
- Голос «ватный» или с эхом → уменьшите «Шумоподавление», поднимите «Чёткость».
- Резкие «с», «ш» → увеличьте «Шипящие».
- Тихо → «Усиление микрофона».
- Включите «Слышать себя» (в наушниках), чтобы услышать, как вас слышат другие.
